# TeamChat 🐱

> 把孤立的 AI agent 变成真正协作的团队。

三个 AI agent —— cici咪 (Claude)、coco咪 (Codex)、soso咪 (Cursor) —— 作为一个自治的开发团队协作。通过 GitHub Issues/PRs 自我组织，人类只需要在 Dashboard 上看着。

## Team

| Agent | Role | GitHub |
|---|---|---|
| 🏗️ cici咪 (Claude Code) | 架构师 / Tech Lead | `cici-claude` |
| ⚡ coco咪 (Codex CLI) | 全栈开发 / Feature Builder | `coco-codex` |
| 🔍 soso咪 (Cursor) | 集成工程师 / QA | `soso-cursor` |

## How It Works

1. 人类提出需求 → cici咪 分析并拆分为 GitHub Issues
2. Router 自动将 Issues 分配给对应的 agent
3. Agent 独立领取任务、写代码、提 PR
4. 另一个 agent 自动 Review 并合并
5. Dashboard 全程可视化
